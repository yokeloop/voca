Модель — LFM3-1.7B Q4_K_M, профиль `lfm3-1.7b` (`VOCA_LLM_PROFILE=lfm3-1.7b scripts/up.sh llm`), все прогоны с thinking on (решение инженера 4). ## Итог

**Рекомендация: ни один ход.** LFM3-1.7B не подходит ни на ход A, ни на ход B.

Рекомендация считается по прогону **«числа цифрами», режим `on`** (`think --modes on --digits`, раздел 4.1, `think-on-digits.tsv`): так решил инженер — «пусть пишет числа цифрами как хочешь решим эту проблему иначе потом».

- **Ход B** требует: числа не ниже 13/18, delegate с размышлением не ниже 9/10, первый звук p50 ниже 5006 мс. Получено: числа **7/18** (Nemotron on — 13/18), delegate **9/10**, первый звук p50 **2478 мс** по 17 ответам с текстом. Время проходит, точность не проходит. Ещё 3 из 20 вопросов остались без ответа: размышление дошло до предела `max_tokens` 1500.
- **Ход A** требует: первый звук p50 с размышлением не выше 1.5 с, диалоги не ниже 17/20. Получено: диалоги **18/20**, первый звук p50 **2478 мс**. Первый звук не проходит.
- С инструкцией «числа словами» (раздел 4) вывод тот же и хуже по времени: числа 8/18, 9 из 20 без ответа, первый звук p50 4623 мс.
- Скорость самого сервера высокая: decode 182 ток/с (Nemotron 71.1), тёплый 8K до первого вывода 90 мс, холодный 8K 606 мс, VRAM 1.4 ГБ. Модель медленна для голоса не скоростью токенов, а длиной размышления: p50 1266 токенов, p95 1500. Nemotron on — 279 / 420.
- Бюджет 128 (необязательный прогон) тоже не проходит: цифрами — 9/18 при первом звуке p50 1991 мс, словами — 12/18 при 2545 мс.

Как считать эту таблицу:

- **Время — по ответам, у которых есть текст.** «Без ответа» — модель потратила все 1500 токенов на размышление, `content` пуст, синтезировать нечего. Такие ответы считаются неверными. В статистику времени они не входят: время считается по 11 ответам из 20 в прогоне `on` и по 7 из 20 в прогоне 1.

Что важно в этих цифрах:

- **Cache_reuse не поддерживается, работают чекпоинты.** Префикс истории берётся из кэша, но хвост ≈ 540 токенов на 8K и ≈ 830 токенов на ход в `turns` пересчитывается заново. Отсюда cache-hit 0.935 против 0.998 у Nemotron. На TTFT это почти не влияет: префилл 540 токенов — 60 мс.
- **Размышление съедает весь бюджет.** 19 из 20 ходов `turns` и все 9 тёплых запросов `points` потратили 1024 токена на размышление, и `content` не появился. Первый content есть только в двух запросах: ход 15 через 4580 мс и холодный 8K через 4453 мс. TTFT по первому выходу показывает скорость сервера, а не время до ответа.
- G4 формально проходит: TTFT 90.1 мс ≤ 300, decode 182.1 ≥ 15.

## 9. Как повторить

Из корня клона. Nemotron VOCA-4 перед этим останавливается там, где был запущен: `scripts/down.sh llm`.

```sh
cp .env.example .env
scripts/fetch.sh
scripts/fetch.sh --check
(cd agent && uv sync --locked)
scripts/ruaccent-setup.sh
scripts/up.sh llm                      # smoke bolt-e4b on b12167
curl -fsS http://127.0.0.1:8081/health
curl -fsS http://127.0.0.1:8081/v1/models
curl -fsS http://127.0.0.1:8081/props
scripts/down.sh llm
VOCA_LLM_PROFILE=lfm3-1.7b scripts/up.sh llm
nvidia-smi --query-compute-apps=pid,process_name,used_memory --format=csv
scripts/up.sh audio                    # if audio.cpp is not already on :8082
uv run --project agent python bench/llm_ru_tools.py dialogs-thinking
uv run --project agent python bench/llm_ru_tools.py delegate-thinking
uv run --project agent python bench/llm_speed.py --thinking
uv run --project agent python bench/tts_pipeline.py think --modes on,b128
uv run --project agent python bench/tts_pipeline.py think --modes on,b128 --digits
scripts/down.sh llm
```

Перед замерами — один прогревочный запрос с размышлением, время загрузки не считается. Скрипты берут имя модели из `GET /v1/models` и пишут выводы в подкаталог `lfm3-1.7b`.
