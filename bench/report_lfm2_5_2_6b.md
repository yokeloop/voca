# Отчёт LFM2.5-2.6B на кейсах E0 (VOCA-8)

Стенд: этот хост (omarchy), RTX 4070 12 ГБ, драйвер 615.78.08, 2026-11-10. Модель — LFM2.5-2.6B Q4_K_M, профиль `lfm2.5-2.6b` (`VOCA_LLM_PROFILE=lfm2.5-2.6b scripts/up.sh llm`). Прогоны — `bench/llm_ru_tools.py dialogs-thinking`, `delegate-thinking`, `bench/llm_speed.py --thinking`, `bench/tts_pipeline.py think`; сырые логи — `.local/bench/llm/lfm2.5-2.6b/` и `.local/bench/pipeline/lfm2.5-2.6b/` (в репозиторий не кладутся). Все числа LFM2.5 ниже — из этих файлов.

Все прогоны с thinking on (решение инженера 4). Режима off у модели нет: это «pure reasoning model that always thinks», шаблон всегда открывает `<think>` и переменную `enable_thinking` не читает. `bench/` по-прежнему шлёт `enable_thinking: true`, на модель это не влияет.

Базовые цифры LFM3-1.7B взяты из `bench/report_lfm3_1_7b.md` со ссылкой на строку. Базовые цифры Nemotron-3.5-Bolt-E4B взяты из прошлых отчётов со ссылкой на строку; все они **измерены на b11869, не перемерялись (решение инженера 3)**.

## Итог

**Рекомендация: ни один ход.** LFM2.5-2.6B не подходит ни на ход A, ни на ход B.

Рекомендация считается по основному прогону **«числа цифрами», режим `on`** (`think --modes on,b128 --digits`, раздел 4, `think-on-digits.tsv`; решение инженера 5).

- **Ход B** требует: числа не ниже 13/18, delegate с размышлением не ниже 9/10, первый звук p50 ниже 5006 мс. Получено: числа **11/18** (Nemotron on — 13/18), delegate **9/10**, первый звук p50 **3387 мс** по 19 ответам с текстом. Время и delegate проходят, точность не проходит.
- **Ход A** требует: первый звук p50 с размышлением не выше 1.5 с, диалоги не ниже 17/20. Получено: диалоги **18/20**, первый звук p50 **3387 мс**. Первый звук не проходит.
- Размышление короткое: p50 168 токенов, p95 757 (Nemotron on — 279 / 420, LFM3 цифрами — 224 / 1500). Первый content p50 952 мс против 4077 мс у Nemotron on и 973 мс у LFM3. Без ответа 1 вопрос из 20 (у LFM3 — 3).
- Первый звук тянет не LLM, а синтез: TTS TTFB p50 1892 мс. Первые предложения длинные, с Markdown и цифрами.
- Против LFM3-1.7B цифрами точнее (11/18 против 7/18), но медленнее до первого звука (3387 против 2478 мс p50).
- Бюджет 128 не спасает: 10/18 при первом звуке p50 2155 мс. Прогон «словами» (необязательный, раздел 4.1) хуже: 2/18 в `on`.
- Скорость сервера высокая: decode 160.7 ток/с (Nemotron 71.1, LFM3 182.1), тёплый 8K до первого вывода 51.6 мс, холодный 8K 740.5 мс, VRAM ≈ 2.0 ГБ.

- `build_info` `b12167-240d68fcf`, `n_ctx` 16384;
- `default_generation_settings`: `temperature` 0.1, `top_k` 50, `top_p` 0.95, `min_p` 0.05, `repeat_penalty` 1.1, `repeat_last_n` 64, `presence_penalty` 0, `frequency_penalty` 0, `dry_multiplier` 0, `n_predict` -1;

`top_p` 0.95 и `min_p` 0.05 — умолчания сервера, команда их не задаёт. Лог загрузки: `chat template supports preserving reasoning, it is enabled by default`, `model loaded` через 3.19 с после старта процесса.

Отличия от профиля B (`bolt-e4b`):

- Нет `--cache-reuse`. В пробном запуске префиксный кэш работал (14702 из 14724 токенов), а сдвинутый префикс не переиспользовался; флаг ничего не даёт. Префикс истории берётся из кэша (`cache_n` в разделе 5).
- Нет `--override-tensor 'per_layer.*=CPU'`: у LFM2.5 нет тензоров `per_layer`, вся модель на GPU.
- Сэмплинг по карточке LFM2.5, а не `--temp 1.0 --top-p 0.95`.

## 8. Как повторить

Из корня клона. Nemotron VOCA-4 перед этим останавливается там, где был запущен: `scripts/down.sh llm`.

```sh
cp .env.example .env
scripts/fetch.sh
scripts/fetch.sh --check
(cd agent && uv sync --locked)
scripts/ruaccent-setup.sh
VOCA_LLM_PROFILE=lfm2.5-2.6b scripts/llama.sh --check
VOCA_LLM_PROFILE=lfm2.5-2.6b scripts/up.sh llm
curl -fsS http://127.0.0.1:8081/v1/models
curl -fsS http://127.0.0.1:8081/props
nvidia-smi --query-compute-apps=pid,process_name,used_memory --format=csv
scripts/up.sh audio                    # if audio.cpp is not already on :8082
uv run --project agent python bench/llm_ru_tools.py dialogs-thinking
uv run --project agent python bench/llm_ru_tools.py delegate-thinking
uv run --project agent python bench/llm_speed.py --thinking
uv run --project agent python bench/tts_pipeline.py think --modes on,b128 --digits
uv run --project agent python bench/tts_pipeline.py think --modes on,b128
scripts/down.sh llm
```

Перед замерами — один прогревочный запрос с размышлением, время загрузки не считается. Скрипты берут имя модели из `GET /v1/models` и пишут выводы в подкаталог `lfm2.5-2.6b`. Последний прогон `think` (словами) необязательный.
